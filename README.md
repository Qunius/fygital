# Fygital

En fristående, animerad nedräkning för https://fygital.se/.

Nedräkningen startade 30 september 2026 kl. 23:50:02 svensk tid och slutar 30 september 2032 kl. 23:50:02. Slutdatumet är gemensamt för alla besökare och återställs inte när sidan laddas om.

Publiceras med GitHub Pages från main, rotmappen. HTML, CSS, JavaScript och originalmaterial från Fygital Design i Figma. Michroma levereras lokalt med sin OFL-licens.
